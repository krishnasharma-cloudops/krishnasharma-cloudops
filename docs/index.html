07 / ENGINEERING NOTESWHAT MATTERS IN PRACTICE

Principles over
pretty pipelines.

A quick look at the engineering decisions behind the technologies I work with.

01Why remote state and locking matter+

Terraform state records managed resources. Remote backends improve collaboration and state locking helps avoid concurrent writes; backend setup and access controls should be planned early.

02What makes a useful landing zone+

Network design, identity, access controls, environment separation and maintainable infrastructure modules make Azure foundations easier to extend than ad-hoc provisioning.

03Security is a pipeline concern+

Linting, static analysis and IaC security scans are more useful when integrated into normal review workflows, not applied only after deployment.

04Where AI fits in engineering+

AI can accelerate code drafts and troubleshooting, but generated Terraform and YAML still need review, validation, security checks and controlled rollout.
